# Workflow: Strict Page Structure

This prompt enforces a rigid structure on the generated layout once the initial hero section is approved.

## Instructions
1. Ensure the document is organized into semantic tags: `<header>`, `<main>`, and `<footer>`.
2. Do not mix global scripts or inline styles into general content.
3. Keep the layout wrapper clear and explicit.
4. Place any new sections inside the `<main>` tag to preserve layout rules.
5. Setup container variables in CSS for clean, consistent margins across all future generated sections.
