# Workflow: Start Project

This prompt is used to generate the initial minimalist hero section based on a reference image.

## Instructions
1. Analyze the structure and styling of the provided hero section screenshot (typography, margins, font pairings, visual alignment).
2. Generate only the hero section using pure HTML, CSS, and vanilla JS. Avoid external UI frameworks.
3. Import high-quality fonts from Google Fonts:
   - Primary Serif (e.g., 'Playfair Display') for elegant headlines.
   - Sans-serif (e.g., 'Inter') for clean UI/metadata text.
   - Monospace (e.g., 'JetBrains Mono') for labels, time, or secondary elements.
4. Setup responsive margins and placeholders for media assets.
5. Provide pure inline and standard styles, keeping them organized.
